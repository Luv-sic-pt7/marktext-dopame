# 第二批：编辑工具与交互修复

基线：`codex/dopame-editor-batch-1 @ 103e7c08`。验证日期：2026-11-14。

本批围绕实际使用反馈完成以下 9 组改动。

| 功能                           | 结果                                                                                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 查找与单处替换（A12、A13）     | 富文本下一处移动真实选区，同段和跨段均正确；长段落把当前匹配滚到视口中部。单处替换只改当前项并可一次撤销；源码和富文本的 Ctrl+F 均聚焦搜索框。                 |
| 表格插入与编辑（B08）          | 顶栏插表不再被同一次点击关闭；空文档和标题焦点下均可选择尺寸或网格插表。单元格点击同步编辑选区，行列增删、对齐、Tab／Shift+Tab、继续输入、撤销和保存往返通过。 |
| 删除线（B11）                  | 顶栏显示明确的“删除线”文字；按钮、Ctrl+Shift+X、源码／富文本往返和撤销可用。                                                                                   |
| 启动入口与正文操作（D01、A15） | 启动入口并入协作中心顶部，移除置顶浮层。正文和侧栏底部控件可直接点击；点击目标段落后按 End 继续输入保持在该段落。                                              |
| 另存为（A07）                  | 保存目标旁提供入口，成功后保存写入新目标；取消和导出保留当前保存目标。原文件、UTF-8 BOM 和 CRLF 均按入口语义保留。                                             |
| 恢复关闭标签（A10、A14）       | 标签栏按钮与 Ctrl+Shift+T 恢复最近关闭的文档；未保存内容、模式和独立撤销历史保留。关闭记录可在重载后恢复，关闭外部文件仅持久化私有草稿。                       |
| 段落与列表（B04、B14）         | 正文、引用、无序、有序和任务列表转换；增加／减少缩进、原生 Tab／Shift+Tab、Enter 续项及空项退出。保留原引擎的新建松列表语义。                                  |
| 任务勾选（B09）                | 每次勾选独立撤销；修复 OT 撤销未更新复选框附件的问题，Markdown 状态与 DOM 显示一致，预览保持只读。                                                             |
| 代码块（B05）                  | 源码选区包裹安全围栏，富文本插入后可直接输入；语言建议、高亮、Unicode 内容、导出重开通过。修复共享 metadata 导致语言标签在导出时残留旧值的问题。               |

## 运行构建包

使用包内应用和配套协作桌面一起启动，确保两部分都来自本次构建。在解压目录执行：

```sh
acde dev ./packages/marktext-dopame --desktop ./packages/marktext-workspace
```

`release-manifest.json` 记录源码提交和构建时间。构建工具同时保持客户端 `.d.ts` 入口位置稳定，供业务工具桥和现有客户端继续使用。

# 移植实现中的一致性边界

上游基线为 MarkText v0.23.0，提交 18fdc1eddc7d36d9b205180d058982f71f4f6373。原始 Electron 应用保留，新实现位于 packages/dopame，使用独立 Bun 锁文件，避免运行根目录的原生重建脚本。

## 文档提交和任务恢复

UI 和 Agent 均通过 DocumentController 处理文档。UI 输入立即取得新 revision，草稿和协作副本异步持久化。Agent 在服务确认 committing 前后再次检查本地版本；尚未落盘时发现新输入，必须明确报告冲突。

Agent checkpoint 已落盘后才发现新输入时，已提交结果必须保留，用户输入保存为独立冲突草稿。不能把旧输入回写到刚完成的 Agent 文档。排队的持久化回调持有同一 Session 对象，因此冲突分支需同步迁移该对象的身份。

checkpoint 包含尚未得到服务确认的 taskId 和提交快照。服务重启把 committing 转为 recovering；执行器核对 checkpoint 后补回结果，无法判定外部文件写入时保留恢复状态。SQLite 任务状态和事件同事务落盘，提交许可不依赖收到网络响应。

## 两种编辑器的历史

Muya 和 CodeMirror 各自保存历史及与该历史对应的正文。历史不能直接套到另一个正文上。模式切换通过 replaceContent 或 CodeMirror 的完整替换操作产生一个边界，文档加载才使用 setContent。UI 未编辑时以原始 Markdown 为准，不因序列化格式变化而更新 canonical text。

Muya 源码使用旧版 TypeScript 装饰器，构建明确启用 legacy decorators。其 Prism 语言加载器原本拼接 node_modules 路径，acdert 不把该路径当可加载模块；构建插件把这个导入改为本地语法包的确定性映射。适配器保留上游依赖加载顺序，源代码结构变化时构建直接失败，避免悄悄漏掉适配。

## 授权

客户端身份由随机凭证确定，payload 中的应用名不是身份。文档、任务、建议和产物有独立访问范围；转授权依赖父授权，父授权过期或撤销后，下游也失去访问。管理员和执行器凭证只写入服务专用的受限目录，不进入源码、Markdown、任务正文或日志。

## 验收目标

用户指定最终在赛事官方真机上测试。本机 acdert 仅用于开发验证。最终包需要独立于 Vite 开发服务器运行；官方真机的服务注册、运行依赖和完整验收未验证前，A10 保持未完成。

## 最终界面检查

本机 acdert 的 1440/768/390 宽度均通过无横向溢出与控件可见检查。浏览器的独立模拟预览另以生产构建检查，0 FAIL、3 WARN。两个 h1 分别属于应用标识与用户 Markdown 文档，保留文档原生语义；正文 17px，工具条与状态辅助信息采用紧凑字号；手机横向工具条保留滚动和贴边按钮，未裁切正文。lint 的 section-label 是导航/大纲分组，shadow 仅用于真实模态浮层。已查看每个原生和浏览器尺寸截图，浏览器检查不代表运行时验收。

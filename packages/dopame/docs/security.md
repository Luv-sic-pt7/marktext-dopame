# 安全、可靠性与恢复记录

范围为本项目的实现复核、自动测试、依赖公告审计和本机 acdert 检查。此记录不表示零漏洞、渗透测试认证或官方真机验收。

## 已处理的问题

1. 未鉴权唤醒请求可能替换健康 worker 连接：先认证候选凭证，验证会话后才更换连接。
2. 私有 checkpoint 写入成功但回报丢失：恢复重新读取磁盘 taskId/revision，不以旧内存判断未提交；无标记时先条件写入恢复栅栏，避免旧请求继续提交。
3. 保存中继续输入可能被误标保存：冻结保存快照，只更新该版本的 savedRevision，新输入继续 dirty。Agent finish 等待期间也保留后续输入；冲突输入可分叉为独立草稿。
4. 过期 lease、服务重启和未确认提交：旧执行器不能完成任务，确定已提交补齐结果；无法核对外部保存时保持 recovering，不自动重复写入。
5. 不确定保存缺少用户出口：可导出/保留独立输入副本；用户明确结束核对后，归档恢复记录并以 OUTCOME_UNKNOWN、retryable=false 结束，不声称成功或回滚。
6. 授权转交重试可能重建已撤销权限：按请求去重，重放返回原授权状态；任务、建议和产物派生授权继承来源链和撤销。
7. 深层非法对象、不完整 Unicode、宽松授权数组：输入先经固定 Schema，再规范化；拒绝截断代理对、重复动作和不合规范时间。传输、队列、文档、分块和租约有明确上限。
8. 新文件导出原先尝试读取不存在的目标：新句柄允许空 baseline，只有既有文件进行比较；不会错误沿用工作文档的磁盘版本。
9. 业务工具接入：只提供具名业务操作，按当前权限过滤目录并逐次鉴权。loopback 拒绝浏览器 Origin、伪造 Host、管理员/worker 凭证及任意路径/命令；stdio 参数不接受明文 token。
10. 只读 TaskRef 交接原先隐含了取消权限：现只允许任务发起方请求取消，管理员另走受控管理操作；只读接收方被拒绝，任务继续保留。
11. 大文件与错误反射：外部文档和图片先核对大小再读取；非法字段名在错误响应中截短，避免放大响应。恢复期间的标题变更和正文一样保留为输入草稿。

## 边界与恢复方法

- 私有工作文档优先使用 acde:fs 的条件写入。外部 FileSystemFileHandle 只能进行读取比较、写入前备份和写后核对，不能宣称原子 CAS；建议优先导入私有工作区，再显式导出。
- 关闭时保留已落盘草稿。若看到“待核对提交”，先保持原任务 ID；允许保留输入副本或导出，不能换新 ID 假装原任务没执行。结束核对会保留 `uncertain/<taskId>.json` 与副本。
- root/句柄权限失效、磁盘冲突、容量错误均保留当前正文。原位保存前的基线备份在 private/recovery；不自动覆盖另一写入者的新版本。
- HTML 在 Muya 中禁用执行，脚本和 javascript 图片协议不执行；未知 Markdown 原样保存的路径经过原生回归。相对位图只从已授权目录读取，正文路径保留。位图限制 8MiB、16384 边长和 16M 像素；不承诺完整扩展渲染。
- 服务依赖本机 Bun 和受信管理员。配对权限是应用协议边界，不能抵抗拥有同一 OS 用户文件权限的恶意进程；不承诺 Dopa 强隔离、可回收已读取明文或跨文件任意崩溃下严格恰好一次。
- 数据库/产物/历史目前没有自动保留清理策略；长期离线、磁盘断电、完整故障矩阵和三会话以上压力仍需后续验证。未验证事项在验收表单独标记，不以普通浏览器或单元测试补写通过。

## 交付前核对

本移植包 ESLint、核心 TS、Vue 类型检查通过，NodeNext 消费者可独立使用打包后的客户端类型。根仓库 pnpm lint 命令触发了整仓依赖准备，已在实际 lint 前停止并恢复独立 Bun 依赖，未将 Electron 根检查记为通过；原始源码和锁文件未变。应用/桌面包不含原生扩展，配对凭证不随包分发，摘要与本地凭证匹配扫描另附报告。

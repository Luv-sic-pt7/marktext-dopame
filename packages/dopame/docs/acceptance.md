## 当前实际链路

原生 E2E 使用两个独立 stdio MCP 进程和不同 client 凭证。写作方创建固定版本，审阅方获 read/propose 后读取大纲和正文、提出建议；无权应用明确拒绝。用户查看差异并确认，完成一次撤销/重做，随后保存、导出、按引用读取结果。撤销产物转授后读取被拒绝。关闭编辑器后，两条查询路径都从服务取得结果。状态进程重启后继续创建成功。

结果从结构化任务/产物接口取得。界面检查仅用于人工编辑、建议确认与窗口行为验证，未通过屏幕读取冒充业务结果。未计入真实模型推理、token、不同 Agent 实现兼容、三会话以上规模或官方设备性能。

## 后置与后续

用户明确暂不安排官方真机入口，M9 保持未测。用户明确将 M3/M4 的真实 Agent 会话验收同样后置。内置 AI、NPU 调度、Dopa 强隔离、完整无窗口执行器、长期清理和大规模压力属于后续范围，不挤占本轮核心流程，也未作为完成项。

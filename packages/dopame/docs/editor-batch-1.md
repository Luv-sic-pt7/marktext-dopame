# 第一批编辑能力改造

基线：`dopame-mvp-0.1.0 @ 03db6ce1`。验证日期：2026-11-14。

这一批完成 7 项用户操作，对应能力清单中的 A11、A12、A13、B11、B14。

| 功能                | 本批结果                                                                                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文档大纲（A11）     | 复用 marked 解析顶层 ATX H1–H6、Setext 和多行标题；跳过 front matter、代码与 HTML 中的伪标题。中文、重复标题和 CRLF 的原文位置保持正确，源码与富文本均可跳转。 |
| 双向查找（A12）     | 上一处、下一处循环导航；显示当前匹配与总数。两种编辑模式使用各自引擎的匹配位置。                                                                               |
| 单处替换（A12）     | 替换当前匹配或全部匹配；源码与富文本中的替换均可一次撤销，包括跨段替换。                                                                                       |
| 搜索选项（A12）     | 区分大小写、Unicode 全词匹配、正则表达式及捕获组替换；非法正则显示错误，预览中禁止替换。                                                                       |
| 快捷键与焦点（A13） | 实测 Ctrl+F/H/S/N/W；Enter、Shift+Enter 和 Escape 操作搜索。输入框撤销保留其自身语义，正文继续输入时搜索刷新保留光标。                                         |
| 删除线（B11）       | 顶栏添加／取消删除线；源码与富文本往返，格式操作具有独立撤销边界。                                                                                             |
| 斜杠插入（B14）     | 接入原版菜单与中文关键字筛选，方向键选择、Enter 确认、Escape 关闭；空结果保留输入，插入新块后可继续中文输入。                                                  |

## 验证

环境为本机 macOS、Bun 1.4.4、acde/acdert/SDK 0.0.9。

- `bun test tests`：52 项通过，包含 10 项新增大纲测试。
- `bun tools/test-native.ts e2e/editing-batch.e2e.ts`：8 项新增原生测试通过。
- 原有 `editor.e2e.ts` 与 `workflow.e2e.ts`：10 项原生测试通过，覆盖 Unicode 选区、文件与图片、模式往返、撤销、权限和协作。
- 共享层 TypeScript、应用层 Vue TypeScript、Dopame ESLint、`acde check`、`acde build` 通过。
- 原生回归检查搜索和富文本替换场景的控制台错误与失败请求；截图覆盖桌面、390px 窄屏、亮暗搜索栏和斜杠菜单。

原生测试使用隔离数据。日志与截图由 `test-native.ts` 保存到 `MARKTEXT_EVIDENCE` 指定目录，默认位于 checkout 外的 `work/marktext-mvp-evidence`。

## 本批范围

大纲保持顶层文档标题范围；引用和列表内部标题不进入主大纲。斜杠查询沿用原插件的不含空格关键字形式。A13 实测使用 Control 修饰键；真实系统输入法预编辑、物理 Command 按键及赛事设备继续按能力清单验收。B14 本批补齐斜杠菜单，其他段落菜单操作仍按原清单逐项回归。

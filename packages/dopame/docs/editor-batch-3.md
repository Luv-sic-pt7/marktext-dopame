# 富文本选区与光标显示修复

基线：`cc86699f`。验证日期：2026-11-14。

本批按实际使用反馈，对照原版 MarkText 的编辑器接入修复三项体验。

| 问题                       | 修复结果                                                                                                                                                                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 选中文字后的浮条只有空白框 | 保留原 InlineFormatToolbar 的格式、选区、颜色和定位逻辑，以 VNode 文字／SVG 替换依赖 PNG 位移和 drop-shadow 的图标。按钮可见，点击保留选区，格式操作独立撤销；亮暗主题与 390px 布局通过。                                                               |
| 删除线两侧展开 `~~`        | 只给删除线分隔符增加 `.mu-del-marker`，在富文本中隐藏。原始 DOM 文本、Markdown 与磁盘内容保留；复制、取消／添加、撤销、Unicode 删除和模式往返通过。左右键只跳过这些隐藏分隔符，真实 DOM 端点保持相同源码偏移，标题、代码和字面波浪线保留。              |
| 富文本竖光标缺失           | 按原版恢复 DOM 焦点并保留有效选区，延续已建立的代码字段焦点。当前 acdert 0.0.9 在 headless／headed 的 contenteditable 中提供正确 Range，但未绘制竖线；新增仅原生模式启用的 DOM Range 光标渲染，随焦点、滚动、主题和窗口激活更新，不改变输入文本或模型。 |

光标在空白新文档、打开文件、切模式／标签、格式操作、撤销／重做、暗色和滚动场景中做了多帧实际像素检测；选中文字、搜索／标题／语言字段、只读预览及非活动窗口中隐藏。

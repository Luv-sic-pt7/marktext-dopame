# 原生菜单、笔记导航与模块调用

基线：`12f7bbaf`。验证日期：2026-11-14。开发环境：macOS Apple M4、acde/acdert/SDK 0.0.9、Bun 1.4.4。

本批完成八组调整：

| 功能       | 结果                                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 主题菜单   | 用应用主题的 DOM 菜单替换原生段落 select，修复暗色白底浅字；支持键盘、Escape、Tab、外点关闭和视口定位。                                    |
| 命令分组   | 常驻编辑按钮收为段落、格式、插入、视图；文件、编辑、段落、格式、插入和视图也注册到系统菜单，复用同一命令。Tab 缩进不注册为应用全局快捷键。 |
| 段落入口   | 补齐 H1–H6、标题快捷键和分隔线；段落转换、格式、插表与代码块保留独立撤销及预览只读。菜单执行停止原点击冒泡，插表面板可以正常停留。         |
| 笔记导航   | 紧凑列表、筛选、折叠、全部／已打开范围；同名笔记显示来源与短 ID，新建自动避开重名。                                                        |
| 笔记操作   | 重命名笔记、创建正文副本、关闭标签并保留草稿；此重命名不改磁盘文件名。                                                                     |
| 视图切换   | 增加文件列表和大纲显隐，保留主题和协作任务入口。                                                                                           |
| 按需渲染   | 空工作区与协作状态面板不初始化 Muya。源码输入桥在窗口启动时注册，富文本渲染和协作面板分别按需初始化，由 acdert 在当前窗口原生渲染。        |
| 协作与恢复 | 协作中心直接显示服务任务，不最小化编辑器；窄窗关闭后返回正文。补上源码选区恢复及关闭最后标签后的焦点接续。                                 |

延后创建源码 textarea 在 acdert 中会重放上一个输入缓冲。已通过真实无换行输入复现，checkpoint 与磁盘均正确；将源码输入桥与富文本渲染拆开后，关闭、重载、恢复草稿不再重复文字，原文件保持显式保存语义。

## 验证

- 原生测试分批有效覆盖 49 个场景：整批运行已有 44 项通过；修复菜单点击冒泡后，表格和菜单 6 项复验通过；状态反馈增加语义名称后，协作和编辑 10 项复验通过。各轮之间包含交集。
- 新增 6 个场景覆盖主题菜单、H2–H6／分隔线、笔记操作、协作入口与模块加载；源码恢复额外核对 checkpoint、真实光标和磁盘内容。
- Dopame ESLint、应用 Vue TypeScript、`acde check`、`acde build` 与 `git diff --check` 通过。
- 已查看明暗主题、1440／768／390px 菜单及笔记截图，检查真实文字对比和弹层边界。截图、日志保存在 checkout 外 `work/marktext-mvp-evidence`。
- 设计沿用 MarkText 绿灰配色与正文优先布局，采用 framed-sheet（seed 1039764807）。菜单阴影属于浮层；侧栏分组标签保留。
